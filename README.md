# Power BI Sales & Profit Performance Analysis

## Project Overview
An interactive Power BI dashboard analysing sales and profitability using the Superstore dataset.

## Dashboard Features
- Sales and profit by category and sub-category
- Monthly sales and profit trends
- Profit margin by category
- Sales by customer segment
- Sales and profit by region
- Top 5 products by profit
- Discount and profit analysis

## Tools Used
- Microsoft Power BI
- Data Analysis
- Data Visualization

## Objective
To analyse business performance and present meaningful insights through interactive dashboards.
